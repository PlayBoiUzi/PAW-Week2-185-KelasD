# Checklist Aksesibilitas Praktikum

- [x] **Struktur HTML5 minimum lengkap** (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- [x] **Elemen semantik digunakan tepat** (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`)
- [x] **Heading berurutan dan halaman memiliki title** (`<title>`, `<h1>`, `<h2>` tersusun rapi)
- [x] **Setiap gambar bermakna memiliki alt text** (gambar ketoprak sudah menggunakan atribut `alt`)
- [x] **Radio/checkbox dikelompokkan dengan fieldset dan legend** (radio button menggunakan `<fieldset>` & `<legend>`)
- [x] **Form memiliki label, id, name, dan required bila perlu** (input menggunakan `<label for="...">`, `id`, `name`, dan `required`)
